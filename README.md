Описание:
    Данный проект реализует программу для управления
    списком студентов и их результатами. 
    Основные функции:
      - ввод данных студентов;
      - сортировка по оценкам;
      - ранжирование результатов;
      - вывод итоговой таблицы.

Назначение:
    Упрощение работы с учебными данными, 
    наглядное отображение успеваемости студентов.
